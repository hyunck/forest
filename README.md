# 확산의 숲 온라인 쉼터

> **확산의 숲 온라인 쉼터**는 한국산림복지진흥원 숲체원에 다녀간 분들이 일상에서 그 숲을 다시 찾을 수 있게 만든 화면 속 쉼터입니다.
> 퇴근하고 10분, 아이를 재우고 나서, 카카오톡으로 받은 링크 하나로 다녀온 숲을 다시 걸어보고, 벤치에 앉아 숨을 고르고 갑니다.
> 그리고 나갈 때쯤, 그 숲의 효과를 연구하는 곳이 있다는 것, 그곳이 **산림복지디지털연구실 효과연구확산팀**이라는 것을 알게 됩니다.
>
> 현장에서 체감하고, 온라인에서 기억합니다.
>
> 원래 '임금님 귀는 당나귀 귀' 이야기에서 대나무숲은 들은 말을 퍼뜨렸습니다.
> 확산의 숲은 당신의 비밀을 퍼뜨리지 않습니다. 대신, 숲이 사람에게 주는 변화를 연구해 널리 알립니다.
>
> *마케팅관리 8조 IMC 전략 시제품 · 실제 서비스가 아닌 수업용 시연물입니다.*

링크 하나로 열리는 3D 웹 쉼터입니다. 작은 아바타로 **국립대전숲체원**(입구 · 잔디광장 · 관망데크 · 골짜기숲길)을 천천히 걸어다니다가, 마음에 드는 자리에 앉아 숨을 고르고, 원하면 고민을 털어놓고 나갑니다.

- 정적 웹사이트입니다. **백엔드(서버)가 없습니다.**
- 털어놓은 말은 어디에도 저장·전송하지 않습니다.
- 함께 보이는 방문자는 실제 접속자가 아닌 **시연용 예시**입니다.

---

## 1. 실행 · 빌드

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

```bash
npm install      # 처음 한 번
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 배포용 빌드 → dist/
npm run preview  # 빌드 결과 미리 보기 (http://localhost:4173)
```

`npm run build`가 끝나면 `dist/` 폴더가 생깁니다. 이 폴더가 배포물 전부입니다.

## 2. 배포

`dist/`는 어떤 정적 호스팅에도 그대로 올릴 수 있습니다(경로가 상대 경로라 하위 폴더에 올려도 열립니다).

### GitHub Pages (이 저장소에 설정되어 있음)

1. GitHub에 새 저장소를 만들고 이 폴더를 `main` 브랜치로 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. 이후 `main`에 올릴 때마다 `.github/workflows/deploy.yml`이 자동으로 빌드해 배포합니다.
4. 주소는 `https://<계정이름>.github.io/<저장소이름>/` 입니다.

### 그 밖의 호스팅

Netlify · Vercel · Cloudflare Pages 등에서는 빌드 명령 `npm run build`, 배포 폴더 `dist`로 지정하면 됩니다. HTTPS만 지원하면 됩니다.

## 3. 시연용 링크

배포 주소 뒤에 아래를 붙여 씁니다.

| 상황 | 링크 |
|---|---|
| 일반 흐름 (홈페이지 게시) | `/?src=homepage` |
| **숲체원 방문자 카톡 사후 메시지** | `/?src=kakao&forest=daejeon&c=demo-family` |
| 재방문 질문 | `/?forest=daejeon&demo=quiz` |
| 측정 시연 | `/?debug=1` |

### URL 파라미터

| 파라미터 | 의미 |
|---|---|
| `forest=daejeon` | 숲 고르기를 건너뛰고 해당 숲으로 바로 |
| `src=kakao` | 진흥원 카카오톡 채널 사후 메시지 (주 경로) |
| `src=homepage` | 진흥원 홈페이지 게시물 |
| `src=booth` | 축제 산림치유 효과 측정 부스 결과지 |
| `src=reporter` | 국민기자단 체험 기사 |
| `src=sns`, `src=search` | 보조 경로 |
| `c=<문자열>` | 발송 대상군 코드(예: `c=2611-daejeon-family`). 화면에 보이지 않고 측정에만 사용 |
| `demo=quiz` | 재방문 질문을 첫 방문에도 띄움 (시연용) |
| `debug=1` | 측정 패널 표시 (방문·설문·질문 집계, FPS) |
| `nowebgl=1` | 3D 대체 화면을 강제로 확인 (점검용) |

## 4. 문구 · 데이터 고치는 법

코드를 몰라도 아래 파일의 글자만 고치면 됩니다. 고친 뒤 `npm run build`를 다시 하면 반영됩니다.

| 고치고 싶은 것 | 파일 |
|---|---|
| **화면의 모든 문구**, 연구원 대사, 표찰, 설문 문항 | `src/data/copy.ts` |
| **연구 주체 서명** (전체 화면에 한 번에 반영) | `src/data/copy.ts` 맨 위의 `SIGNATURE_FULL`, `SIGNATURE_SHORT` |
| 숲 목록, 지역 표기, 열림/잠김, 진입 문구, 예약 주소 | `src/data/forests.json` |
| 건물 · 길 · 벤치 · 연구원 · 표찰 · 정원등 위치 | `src/scenes/daejeon/layout.ts` |
| 하늘 · 조명 · 나뭇잎 색 (계절) | `src/scenes/seasons.ts` |
| 아바타 옷 색 | `src/data/outfits.ts` |

`forests.json`의 `entryLine`은 숲 진입 로딩의 둘째 줄입니다. 특정 숲에서 실제 진행된 연구가 확인되면 그 숲의 문구만 바꿀 수 있습니다. `bookingUrl`을 비우면 "예약 페이지는 준비 중이에요." 안내가 뜹니다.

### 표기 규칙

- 공간명은 항상 **확산의 숲**, 서비스 설명이 필요할 때는 **확산의 숲 온라인 쉼터**
- 연구 주체(출처)는 **한국산림복지진흥원 산림복지디지털연구실 효과연구확산팀** / **산림복지디지털연구실 효과연구확산팀** (다른 표기 금지)
- 문구는 "~연구하고 있어요"로 끝내고, 효과를 단정하는 표현은 쓰지 않습니다.
- '치료' 대신 '치유'. 환자 · 질환과 연결하는 표현은 쓰지 않습니다.
- 연구 수치(%, 명, 점수)는 넣지 않습니다.

## 5. 조작

| 동작 | 방법 |
|---|---|
| 걷기 | 가고 싶은 곳을 누르기 (PC는 방향키 · WASD도 가능) |
| 시선 돌리기 | 화면 드래그 (선택 기능) · 확대/축소는 두 손가락 또는 휠 |
| 앉기 · 숨쉬기 · 털어놓기 | 하단 버튼 (PC 숫자키 1 · 2 · 3) |
| 장소 바로가기 | `장소` 버튼 → 숲 입구 · 잔디광장 · 관망데크 · 골짜기숲길 |
| 나가기 | `나가기` 버튼 (PC는 Esc) |

엘리베이터 타워에 들어가면 데크로드로 오르내립니다(대전숲체원의 특징).

## 6. 폴더 구조

```
src/
  main.ts                 화면 흐름 (로딩 → 고르기 → 진입 로딩 → 숲 → 종료)
  style.css               디자인 시스템 (색 · 큰 글씨 · 버튼)
  data/                   copy.ts(문구), forests.json(숲 목록), outfits.ts
  core/                   링크 파라미터, 측정(로컬), 소리(직접 합성), 도우미
  ui/                     화면들, HUD, 털어놓기, 측정 패널, 3D 대체 화면
  game/ForestGame.ts      이동 · 카메라 · 앉기 · 엘리베이터 · 상호작용
  world/                  지형, 길찾기, 건물, 소품, 나무, 하늘, 아바타, 파티클
  scenes/daejeon/         국립대전숲체원 배치 데이터와 장면 조립
  scenes/seasons.ts       계절 팔레트 (가을 기본, 봄 벚꽃은 정의만)
  presence/               함께 있는 방문자 (지금은 시연용 MockPresence)
```

- **숲 추가**: `forests.json`에 항목을 추가하고 `src/scenes/<id>/` 폴더(배치 데이터 + 장면 조립)를 만들면 됩니다.
- **실시간 동시접속**: `src/presence/PresenceProvider.ts` 인터페이스를 실제 서버로 구현하면 됩니다. 주고받는 것은 "누가 어디에 있고 어느 자리에 앉아 있는지"뿐이고, 1~2초 간격 전송을 전제로 화면에서 보간합니다. 이번 범위에는 포함하지 않았습니다.

## 7. 개인정보 · 안전

- **털어놓기 입력은 저장 · 전송하지 않습니다.** "숲에 묻기"를 누르는 순간 입력창과 변수를 비우고, 흩어지는 연출이 끝나면 낱글자도 비웁니다. 측정에는 횟수만 남습니다.
- 위기 표현(예: "죽고 싶", "자살")이 감지되면 흩어지는 연출 대신 **자살예방 상담전화 109** 안내를 띄웁니다.
- 쿠키와 외부 분석 도구를 쓰지 않습니다. 측정은 브라우저의 `localStorage`(`hwaksan_metrics`)에만 쌓이며 외부로 나가지 않습니다.
- 설문 응답도 로컬에만 기록하고 개인을 식별할 정보는 받지 않습니다.

## 8. 성능 · 호환

- WebGL을 쓸 수 없으면 같은 장소를 그린 정지 그림 + 같은 문구와 버튼의 대체 화면으로 자동 전환합니다.
- 첫 3초 평균 30fps 미만이면 그림자 · 파티클 · 후처리를 자동으로 낮춥니다.
- `prefers-reduced-motion` 설정 시 파티클과 카메라 움직임을 줄이고, 장소 바로가기를 페이드 전환으로 바꿉니다.
- 참고 이미지(`reference/`)는 저장소와 배포 빌드에 넣지 않습니다. 진흥원 로고 · CI와 공식 안내도 그림은 쓰지 않았습니다.
